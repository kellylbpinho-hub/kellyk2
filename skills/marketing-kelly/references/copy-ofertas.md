# Copy e ofertas

> Para o curso Kaizen, use também a skill `kaizen-copywriter`, que tem o tom do método.

## Anatomia de uma oferta
Resultado prometido + mecanismo (como funciona) + prova (casos, números, depoimentos reais) +
garantia + preço ancorado + prazo/escassez **real** + CTA único.

## Estruturas úteis
- **PAS**: Problema → Agitação → Solução.
- **AIDA**: Atenção → Interesse → Desejo → Ação.
- **Antes/Depois/Ponte**.

## Landing page
Acima da dobra: headline com resultado, subheadline com prazo/público, prova rápida, CTA.
Depois: dor, solução, como funciona, prova, FAQ de objeções, garantia, CTA repetido.

## Regras
- Nunca inventar depoimento, número ou escassez. Isso é enganoso e viola regras de plataformas e o
  CDC. Usar apenas prova real; se não houver, dizer que falta e sugerir como conseguir.
- Escrever para uma pessoa, na linguagem que ela usa. Entregar 2 variações de headline para teste.
